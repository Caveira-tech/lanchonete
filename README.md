# Lanchonete

Página web para uma lanchonete, com catálogo de produtos e carrinho de pedidos.

## Funcionalidades

- Exibição de lanches e bebidas.
- Seleção de produtos, quantidade e observações.
- Carrinho com forma de pagamento e endereço de entrega.
- Envio do pedido pelo WhatsApp.
- Avaliação da experiência do cliente.
- Painel administrativo em `admin.html` para gerenciar produtos, pedidos e configurações.

## Como usar

Abra o arquivo `index.html` no navegador para acessar a página principal. O painel administrativo pode ser acessado pelo arquivo `admin.html`.

Os dados configurados no painel são armazenados no `localStorage` do navegador.

## Publicação

Este projeto usa apenas HTML, CSS e JavaScript, sem etapa de build. Para publicar no Vercel, importe o repositório do GitHub e faça o deploy mantendo as configurações padrão.
